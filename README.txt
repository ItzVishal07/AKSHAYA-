AKSHAYA OFFICIAL WEBSITE
========================

Files:
- index.html          Website content and page sections
- style.css           Corporate responsive design and logo-derived colors
- script.js           Mobile navigation, scroll reveal, gallery placeholder interactions,
                      and a team-interest form that opens a pre-filled email
- assets/akshaya-logo.png  Logo extracted from the supplied Akshaya logo PDF

CONTACT
General enquiries and team applications: akshaya.admininfo@gmail.com

LOCAL PREVIEW
1. Keep the files in the same folder structure.
2. Open index.html in a browser. For best testing, use VS Code with Live Server.

GITHUB PAGES
1. Create or open the GitHub repository for the website.
2. Upload index.html, style.css, script.js, README.txt and the assets folder.
3. In repository Settings > Pages, select the publishing branch and root folder.
4. Save and open the generated GitHub Pages URL.

IMPORTANT
- This is a static front-end site. The application form opens the visitor's email application;
  it does not save submissions to a database.
- The admin dashboard is intentionally not included in this phase.
- Team, event, project and gallery content includes clearly marked placeholder concepts.
  Replace them with confirmed Akshaya details before public launch.
- Fonts load from Google Fonts when internet access is available; fallback fonts are included.
